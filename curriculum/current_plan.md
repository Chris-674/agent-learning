# AI Agent Developer Learning Plan

## Goal
独立设计、构建、部署 AI Agent 项目。

## 学习阶段

### Phase 1: Python 基础（Week 1-4）
- W1: Python 基础、数据结构、控制流
- W2: 函数、装饰器、面向对象基础
- W3: 类型提示、模块、包、项目结构
- W4: 异步、错误处理、测试

### Phase 2: 工程实践（Week 5-6）
- W5: Git、GitHub 工作流、代码评审
- W6: 调试、日志、项目架构

### Phase 3: AI/LLM 基础（Week 7-9）
- W7: 什么是 LLM、token、上下文窗口
- W8: Prompt 工程、函数/工具调用
- W9: Embedding、向量数据库、RAG 基础

### Phase 4: Agent 开发（Week 10-14）
- W10: 从零构建一个 Agent（不用框架）
- W11: LangChain Agent、ReAct 模式
- W12: 记忆、状态管理
- W13: 工具设计、多步推理
- W14: 多 Agent 系统、编排

### Phase 5: 生产化（Week 15-16）
- W15: FastAPI、打包、部署
- W16: 监控、可观测性、扩展
