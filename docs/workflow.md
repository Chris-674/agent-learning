# AI Agent Learning Workflow

## Objective

Build a long-term, cross-device AI Agent learning system.

## Roles

### ChatGPT

Responsible for:

- Planning the learning roadmap
- Generating the daily learning plan
- Reviewing learning progress
- Adjusting the curriculum
- Generating the prompt for Codex

### Codex

Responsible for:

- Teaching
- Writing code
- Assigning exercises
- Reviewing code
- Updating learning records

### GitHub

Acts as the single source of truth.

Stores:

- Learning status
- Notes
- Exercises
- Projects
- Learning history

## Daily Workflow

1. ChatGPT reviews the current progress.
2. ChatGPT generates today's learning plan.
3. The plan is sent to Codex.
4. Codex teaches and assigns exercises.
5. Codex updates the learning records.
6. ChatGPT reviews the updated records and plans the next session.
